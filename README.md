# Idea Vault

A small command-line Python application for storing and reviewing project ideas.

## Purpose

Idea Vault was created as a personal project to practice Python programming, file handling, command-line interaction, and Git/GitHub version control.

## Current Features

- Store ideas in a text file
- Read saved ideas from the command line
- Simple command-based interface

## Technologies

- Python
- Git
- GitHub
- PowerShell

## Project Status

Early development. Features will be added as the project evolves.

## What I'm Learning

This project is part of my ongoing exploration of Python development and version control. Future improvements will include better input handling, additional commands, and improved organization of stored ideas.
